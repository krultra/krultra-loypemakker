# Versjon 2.0.0 — Første offentlige utgivelse

*14. juli 2026*

KrUltra Løypemakker (KUL) ble med denne utgivelsen **åpen kildekode**,
publisert på [GitHub](https://github.com/krultra/krultra-loypemakker) under
MIT-lisens — fri å bruke, endre og dele, også kommersielt, med kreditering.

## Hovedinnhold

- **Produktnavn og identitet:** «KrUltra Løypemakker», forkortet KUL, med
  logo, favicon og oppstartsfil `KUL.bat` (tidligere `run.bat`).
- **«Send til KrUltra»**: arrangører uten egen server kan lage en
  `.loype`-fil (bærer punkter, veipunkter, stil og alle metadata) og sende
  den til KrUltra for publisering på loyper.krultra.no — med tilhørende
  importfunksjon.
- **Klar for offentligheten:** billedlagt installasjonsguide
  ([INSTALLASJON.md](INSTALLASJON.md)), bruksveiledning
  ([BRUK.md](BRUK.md)), endringslogg, HTML-versjoner av all dokumentasjon,
  GitHub-maler for feilrapporter og funksjonsforslag, og sikkerhetsherding
  (XSS-validering i publisert visning, opplastingsgrense på GPX-parsing).
- **Semantisk versjonering** (MAJOR.MINOR.PATCH) ble innført fra og med
  denne utgivelsen — se skjemaet i [CHANGELOG](../CHANGELOG.md).

## Bakgrunn

2.0.0 tilsvarer den interne utviklingsversjonen «v19». Hele
utviklingsløpet fra MVP til første offentlige utgivelse er dokumentert i
versjonsnotatene [versjon-2](versjon-2.md) til og med
[versjon-19](versjon-19.md) — se særlig [versjon-19](versjon-19.md) for
detaljene i selve lanseringsrunden.
